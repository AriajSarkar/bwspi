## Interpretation boundaries

BWSPI retains duplicates and supports storage IDs, ordered snapshots, updates, and removes. `HashSet` deduplicates values and is only a membership set. The `HashSet` memory number is a capacity lower bound because the standard library does not expose exact heap bytes.
